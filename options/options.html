Colorize UI

確認対象ドメインを指定し、hostname の環境キーワード（または prefix なし = PROD）で 枠線とバナーの色を変えます。

確認対象ドメイン

色分けしたいサービスのドメインを1行ずつ指定してください。未指定のあいだはどのページにも色は付きません。 ここに書いたドメイン配下で、dev / stg などの prefix が無い hostname は PROD（赤） として扱います。

基本

環境ルール

上から順にキーワード判定します。「prefixなし用」にチェックしたルールは、 どのキーワードにも当てはまらない確認対象ドメインのフォールバック（既定: PROD 赤）になります。
